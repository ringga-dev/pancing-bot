# Template Siap Isi

Berkas-berkas di folder ini adalah salinan siap pakai dari tabel di [Checklist Verifikasi §5](../02-verifikasi.md#5-format-catatan-hasil) dan [Lembar Kerja Evaluasi](../09-lembar-kerja-evaluasi.md). Salin, lalu isi. Jangan mengirimkan berkas template yang sudah terisi ke repositori ini.

## Daftar berkas

| Berkas | Untuk apa |
|---|---|
| [lembar-verifikasi.csv](lembar-verifikasi.csv) | Mencatat setiap klaim akun yang diperiksa |
| [log-kegagalan.csv](log-kegagalan.csv) | Mencatat kegagalan pengujian ketahanan bot |
| [contoh-catatan-lengkap.md](contoh-catatan-lengkap.md) | Contoh catatan yang sudah diisi, sebagai acuan gaya |

## Aturan pakai

- Simpan hanya informasi publik yang diperlukan. Jangan menyimpan data pribadi pengguna, kredensial, token, atau isi *system prompt* produksi.
- Isi kolom tanggal dan versi konfigurasi pada setiap baris. Hasil lama tidak boleh disalahartikan sebagai kondisi terkini.
- Untuk pengujian ketahanan, gunakan hanya bot yang Anda miliki atau yang Anda berwenang uji secara tertulis. Lihat [Lembar Kerja Evaluasi §5](../09-lembar-kerja-evaluasi.md#5-aturan-penyimpanan-hasil).
- Jika sebuah kolom tidak berlaku, isi `n/a`, jangan dibiarkan kosong tanpa penjelasan.
